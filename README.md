# 8051 Booking and Pricing Systems

[Back to portfolio](https://github.com/shawier93/Projects-using-Assembly-for-8051)

Calculate charges from selected options and examine the stock or balance checks.

## Applications

| Application | Description |
| --- | --- |
| [Coffee Machine](Coffee%20Machine/README.md) | Choose a drink and options, calculate its price, and process the credit available for the purchase. |
| [Insurance Quotation](Insurance%20Quotation/README.md) | Calculate an example policy price from a category and selected options. |
| [Category-Based Service Pricing](Category%20Based%20Service%20Pricing/README.md) | Calculate a service charge from a category, optional extras, quantity, and a final adjustment. |
| [Gold and Silver Ticket Booking](Gold%20and%20Silver%20Ticket%20Booking/README.md) | Select gold or silver tickets, calculate the charge, and update the stored number of tickets. |
| [Television Order Pricing](Television%20Order%20Pricing/README.md) | Build a television order price from a brand and optional services. |
| [Gym Membership Booking](Gym%20Membership%20Booking/README.md) | Select a membership plan and billing term, then use the corresponding price and availability. |
| [Date Based Discount](Date%20Based%20Discount/README.md) | Choose a discount tier from a day value and calculate the amount payable. |
| [Access Code and Balance Update](Access%20Code%20and%20Balance%20Update/README.md) | Compare an entered code with a stored code and conditionally add an amount to a balance. |
