# Access Code and Balance Update

[Repository overview](../README.md)

Compare an entered code with a stored code and conditionally add an amount to a balance.

## Implementations

The two listings use different preset balances and additions. Their comparisons also differ: a self-comparison does not validate the intended limit. Treat the checks as code exercises, not an access-control product.

| Implementation | Input | Output |
| --- | --- | --- |
| [Fixed Input Code And Amount Update](Fixed%20Input%20Code%20and%20Amount%20Update/README.md) | Values stored in memory | Internal memory |
| [Code Verified Capacity Check](Code%20Verified%20Capacity%20Check/README.md) | Values stored in memory | Internal memory |
